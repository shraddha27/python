ℹ️ How Indexing Works

  • Embedding Generation: Each task is converted to a 384-dimensional vector using sentence-transformers
  • Vector Storage: Embeddings are stored in Postgres with pgvector extension
  • Semantic Search: Later, you can search tasks by meaning, not just keywords
  • AI Context: The AI assistant uses indexed documents to answer questions with relevant context
